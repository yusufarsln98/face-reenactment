    \begin{columns}[c]
        \begin{column}{0.50\textwidth}
            \begin{alertblock}{Why Did Face Swapping Fail?}
                \small
                \begin{itemize}
                    \item \textbf{No Visual Progress:} Comparing 50 vs. 150 epochs showed no discernible improvement.
                    \item \textbf{Reconstruction vs. Identity:} The A $\to$ B face did not look like Person B, and B $\to$ A did not look like Person A.
                    \item \textbf{Objective Flaw:} Pixel-wise MSE trained the model to recreate the original face, not transfer identity.
                    \item \textbf{Dataset Size:} 238 total images were insufficient to learn a generalized, disentangled latent space.
                \end{itemize}
            \end{alertblock}
        \end{column}
